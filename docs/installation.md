# Installation Guide

In this guide, you will need to install Espanso on your system using your
preferred method. It may be installed via package managers, direct downloads,
or from source. Follow the instructions based on your operating system.

Once installed, you will need to copy over the configuration files to the
configuration directory for your operating system. The configuration files are
found in the `espanso` directory of this repository. If you do not have any
other configuration files (this is your first time installing/using Espanso on
your computer), you can copy the entire `espanso` directory of this repository
directly to your computer.
